# Example parameter file for cuvslam_api_launcher.
#
#   ./bin/cuvslam_api_launcher --params=api_params.txt --edex=<edex file>
#
# One "key: value" per line; "key = value" also works, and # starts a comment. Every entry is
# optional -- anything left out keeps its built-in default.
#
# Run with --list_params to print every name with its type, default and description. Repeatable
# -Pkey=value overrides single entries and wins over this file, and any unambiguous suffix of a
# name works, so -Pnum_desired_tracks=300 reaches sof.num_desired_tracks.
#
# An unknown name is an error rather than a warning, so a typo here fails the run instead of
# silently doing nothing.
