Welcome to PyCuVSLAM API documentation!
=======================================

PyCuVSLAM provides Python bindings for the cuVSLAM (CUDA-accelerated Visual SLAM) library.

For global localization, in a saved map without a guess pose, see
`doc/place_recognition.md <https://github.com/nvidia-isaac/cuVSLAM/blob/main/doc/place_recognition.md>`_.
